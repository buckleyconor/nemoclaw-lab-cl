# GPU ECC Double-Bit Error on Mobile NVIDIA RTX — Detection and Recovery

> **PLACEHOLDER** — SME: replace with real DCGM / nvidia-smi output and Dell hardware diagnostic guidance for RTX Ada mobile GPUs.

## Summary

An ECC Double-Bit Error (DBE) indicates that the GPU detected an uncorrectable error in VRAM — two or more bits in the same memory word have flipped beyond what ECC can correct. Unlike Single-Bit Errors (SBE), DBEs cannot be silently repaired and may corrupt computation results. The GPU reports the fault via DCGM health check or nvidia-smi ECC counters.

## Affected products

- Dell Precision 7780 / 7680 with NVIDIA RTX 5000 / 4000 Ada Generation (ECC-capable VRAM)
- NVIDIA driver 525.x+ with ECC enabled
- DCGM 3.x health monitoring

## Symptoms

- `dcgmi health -g 0 -s g` returns `DBE` failure for memory
- `nvidia-smi --query-gpu=ecc.errors.uncorrected.volatile.total --format=csv` returns > 0
- Application crashes with `CUDA error: uncorrectable ECC error encountered`
- DCGM Field ID 312 (DCGM_FI_DEV_ECC_DBE_VOL_TOTAL) > 0

## Root cause

1. **Cosmic ray bit-flip** — rare but possible; single occurrence may not indicate hardware failure
2. **Thermal stress** — sustained high GPU temperature accelerating VRAM degradation
3. **Hardware defect** — VRAM chip fault requiring GPU replacement
4. **Electrical transient** — power supply instability affecting GPU memory voltage rail

## Remediation steps

### Step 1 — Drain GPU workloads

Terminate all active compute processes before proceeding:

```bash
nvidia-smi --query-compute-apps=pid --format=csv,noheader | xargs -r kill -9
```

### Step 2 — Run ECC diagnostic

```bash
# Check volatile (since last reboot) and aggregate (all-time) ECC counts
nvidia-smi --query-gpu=ecc.errors.corrected.volatile.total,ecc.errors.uncorrected.volatile.total,ecc.errors.corrected.aggregate.total,ecc.errors.uncorrected.aggregate.total --format=csv

# DCGM health check
dcgmi health -g 0 -s gmip
```

### Step 3 — Reset ECC counters and reboot

A single DBE after a cosmic-ray event may self-resolve after reboot:

```bash
# Reset volatile ECC counters
nvidia-smi --ecc-config=1   # Ensure ECC is enabled
nvidia-smi -r               # Reset GPU (clears volatile counters)
# Reboot the system
shutdown -r now
```

After reboot, re-run the diagnostic. If DBE volatile count is 0 and no new errors appear under workload, the event was transient.

### Step 4 — Escalate if persistent

If DBE reoccurs within 24 hours of workload resumption:

- File a Dell hardware support ticket with `nvidia-bug-report.log` and dcgm health history
- The GPU VRAM requires replacement (covered under Dell ProSupport)
