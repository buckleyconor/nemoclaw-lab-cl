# NVLink Fabric Link Failure on XE9680 — Detection and Remediation

> **PLACEHOLDER** — SME: replace body with the real Dell KB article for NVLink failures on XE9680 / NVSwitch.

## Summary

The XE9680 uses an NVSwitch fabric to connect all 8 H100 GPUs at 900 GB/s per link. An NVLink fabric failure (`nvlink_recovery_error`) means at least one inter-GPU link has entered an error state and entered recovery mode. Distributed training workloads will hang or produce incorrect results if NVLink is degraded.

## Affected products

- Dell PowerEdge XE9680 with NVSwitch-based NVLink fabric

## Symptoms

- iDRAC Lifecycle Log shows `OEM.1.0.NVLinkDown` with severity Critical
- Kernel log: `NVRM: nvlink_recovery_error on NVSwitch port <n> (GPU <i>, link <j>)`
- DCGM: `NVLink error count exceeded threshold on GPU pair (<i>,<j>)`
- `nvidia-smi nvlink --status` shows one or more links in error or inactive state
- NCCL collective communication timeouts in distributed training jobs

## Root cause

Common causes:

1. NVSwitch port CRC errors (signal integrity, PCB trace issue)
2. NVLink cable or connector damage (discrete NVLink systems)
3. GPU firmware issue triggering link fault
4. Thermal event causing link instability

## Remediation steps

### Step 1 — Cordon and drain affected node

```bash
kubectl cordon gpu-server-02
kubectl drain gpu-server-02 --ignore-daemonsets --delete-emptydir-data
```

All active NCCL jobs must be terminated before resetting the fabric.

### Step 2 — Reset NVLink fabric via iDRAC

A full power cycle is the most reliable way to reset the NVSwitch fabric:

```bash
racadm serveraction powercycle
```

Allow 3–5 minutes for full POST and GPU enumeration before proceeding.

### Step 3 — Verify fabric recovery

```bash
nvidia-smi nvlink --status -i 0   # check all links on GPU 0
dcgmi nvlink -g 0 --link-status
```

All links should show `Active` state. Run a quick NCCL bandwidth test to confirm fabric throughput:

```bash
/usr/local/cuda/samples/bin/x86_64/linux/release/all_reduce_perf -b 1G -e 1G -f 2 -g 8
```

## Escalation

Persistent NVLink errors after power cycle indicate a hardware fault. Engage Dell support for NVSwitch diagnostics or GPU/board replacement.
