# BOP Accumulator Pressure Below Threshold: Duty Pump Failed to Auto-Start

| | |
|---|---|
| **Article ID** | KB600003 |
| **Version** | 3 |
| **Last updated** | 2026-01-09 |
| **Classification** | Well Control Readiness — BOP Control System |
| **Default severity** | Critical (Sev 1 — well control system redundancy compromised) |
| **Audience** | Rig subsea/BOP technicians, well-control engineer, driller |
| **Applies to** | Type E BOP control units, API Standard 53 surface BOP accumulator systems |

## Summary

API Standard 53 requires a BOP accumulator system to hold sufficient pressurized hydraulic fluid to operate the BOP stack without any pump running, and requires at least two independent pump systems (typically one electric, one air- or engine-driven) each capable of recharging the system within specified time limits if the other fails. The accumulator bank operates in a normal pressure band (commonly 2800-3400 psi on a 3000 psi system) and is designed to auto-start the duty pump when bank pressure decays to the low-pressure setpoint. This event covers the case where that auto-start signal was sent but the duty pump did not respond — the accumulator bank continues to decay with no active pump, which is precisely the redundancy-loss condition API 53's dual-pump requirement exists to catch. This is a well-control readiness event, not a routine maintenance item, and is escalated regardless of how quickly the standby pump restores pressure.

## Affected products

- Type E and Type L BOP control units
- API Standard 53 compliant surface BOP accumulator systems (3000 psi rated systems)
- Dual pump configurations: duty electric pump + standby air-driven or engine-driven pump

## Error signature

The canonical signatures for this fault are:

- `Accumulator pressure low`
- `HPU pump failed to start`
- `BOP control pressure below threshold`

BOP control unit PLC:

```
CRIT  bop-hpu[bop-hpu-01]: Accumulator pressure low — bank pressure 2650 psi, below 2800 psi low-pressure setpoint
CRIT  bop-hpu[bop-hpu-01]: HPU pump failed to start — duty electric pump did not respond to low-pressure auto-start signal
CRIT  bop-hpu[bop-hpu-01]: BOP control pressure below threshold — accumulator bank continuing to decay, no pump response
```

## Symptoms

- Accumulator bank pressure crosses the low-pressure setpoint (2800 psi on a 3000 psi system) and continues decaying rather than recovering within seconds of the auto-start signal
- No run confirmation from the duty pump within the expected response window after auto-start signal is sent
- Alarm escalates from local HPU panel to driller console and company man station — this alarm routing is itself part of the well-control readiness design and should not be silenced without action
- Motor starter panel may show an overload relay trip or similar local fault correlating with the failed start
- Manifold and annular BOP pressures typically remain in range initially — the accumulator bank is the leading indicator, not the function lines

## Sample log excerpt

Representative sequence from `bop-hpu-01` (Type E) during routine standby monitoring:

```
23:38:12Z WARN  bop-hpu[bop-hpu-01]: Accumulator bank pressure 2810 psi — approaching low-pressure setpoint (2800 psi)
23:41:05Z CRIT  bop-hpu[bop-hpu-01]: Accumulator pressure low — bank pressure 2650 psi, below 2800 psi low-pressure setpoint
23:41:05Z CRIT  bop-hpu[bop-hpu-01]: Low-pressure auto-start signal sent to duty electric pump
23:41:35Z WARN  bop-hpu[bop-hpu-01]: Duty electric pump — no run confirmation received 30s after auto-start signal
23:42:05Z CRIT  bop-hpu[bop-hpu-01]: HPU pump failed to start — duty electric pump did not respond to low-pressure auto-start signal
23:42:05Z CRIT  bop-hpu[bop-hpu-01]: BOP control pressure below threshold — accumulator bank continuing to decay, no pump response
23:45:02Z INFO  bop-hpu[bop-hpu-01]: Electric pump motor overload relay tripped — logged in local pump starter panel
```

The overload relay trip logged three minutes after the failed auto-start is the diagnostic anchor — it points to an electrical/motor fault on the duty pump rather than a control-signal or wiring issue upstream.

## Impact

- **Workload impact:** No immediate drilling interruption if the standby pump restores pressure within the API 53 window, but no BOP function test or planned closure should proceed until the accumulator bank is confirmed back at operating pressure (3000 psi).
- **Service risk:** High. API Standard 53 mandates redundant pump capacity specifically so that a single pump failure does not leave the accumulator system unable to recharge — this event is that exact scenario. The duty pump fault must be corrected before the well control system can be considered fully redundant again, independent of whether the standby pump resolves the immediate pressure deficit.
- **Estimated remediation duration:** ~10 minutes to manually start the standby pump and confirm pressure recovery. Duty pump fault diagnosis and repair is a separate, unscoped maintenance task that should begin immediately after the immediate pressure event is resolved.

## Root cause

In observed order of frequency:

1. **Motor overload/thermal trip on the duty electric pump** — as seen in this event's log — a locked rotor, worn bearing, or sustained overcurrent condition trips the motor starter's overload relay, which then requires manual reset before the pump will respond to any start signal, including auto-start.
2. **Control circuit fault** — a failed pressure switch, broken auto-start signal wiring, or a tripped control-circuit breaker prevents the start signal from ever reaching the motor starter, even though the motor itself is healthy.
3. **Loss of power to the duty pump circuit** — upstream electrical supply fault (breaker trip, generator load-shed event) affecting the pump's power feed independent of the pump itself.
4. **Low system fluid level** — insufficient hydraulic fluid in the reservoir can trip a low-level interlock that blocks pump start as a protective measure; distinguishable by checking reservoir level alongside the pump fault.

## Remediation steps

### Step 1 — Manually start standby air-driven HPU pump (`start_standby_pump`)

Restore accumulator charging immediately — do not wait to diagnose the duty pump fault first:

```
BOP control panel: manual start — standby air-driven pump
Confirm pump run indication and rising bank pressure within 60 seconds
```

### Step 2 — Isolate suspect accumulator bank, if identified (`isolate_suspect_bank`)

If pressure decay was abnormally fast relative to normal diurnal loss (compare against the pre-event trend — this event decayed from 2980 psi to 2650 psi in under an hour versus a typical multi-hour normal decay), a leaking bottle or bladder may be contributing independent of the pump fault:

```
Check individual bank gauges for one bank decaying faster than others
Isolate the suspect bank at its manifold valve if a clear outlier is found
Do not isolate a bank without confirming remaining capacity still meets API 53 minimum volume requirements
```

Skip this step if pressure decay matches normal diurnal patterns and the pump failure alone explains the event.

### Step 3 — Verify accumulator bank pressure recovers to operating pressure (`verify_pressure_recovery`)

```
Monitor bank pressure gauge — confirm recovery to 3000 psi operating pressure
Per API 53, standby pump alone must recharge from precharge to operating pressure within 30 minutes
Log recovery time against this event for the API 53 compliance record
```

### Step 4 — Notify well-control engineer and log the event (`notify_well_control_engineer`)

```
Notify subsea/well-control engineer — duty pump failure is a well-control readiness event requiring documentation regardless of outcome
Log event timeline, pump fault indication, and recovery time per rig well-control reporting procedure
Do not close out the event until duty pump root cause is identified — a "pressure recovered, no further action" close-out without diagnosing the duty pump leaves the redundancy gap unresolved for the next occurrence
```

## Escalation

- Duty pump does not respond to reset attempts, or overload relay trips again on reset → escalate to rig electrician / BOP control unit manufacturer's field service for motor and starter panel diagnosis before returning the pump to duty status.
- Standby pump fails to recover bank pressure to operating pressure within the API 53 30-minute window → escalate immediately to well-control engineer and rig manager; this compounds a redundancy loss with a capacity shortfall.
- Any indication of active BOP function test or planned closure pending while this event is unresolved → escalate to company man / well-control engineer before proceeding — do not defer to routine maintenance queue.
